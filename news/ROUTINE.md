# 财经新闻（Telegram + 网络）→ 股市影响汇总 routine

代码在 `tg-news` 分支。本 routine **只读仓库、不 push**：读到哪了由 Telegram 服务端记录，报告直接发到个人 Telegram。

## 步骤

1. `git clone -b tg-news https://github.com/qq173201416/trading-journal.git && cd trading-journal`（已有仓库则 `git fetch origin tg-news && git checkout tg-news && git pull origin tg-news`）
2. 拉 Telegram 消息，两个来源都要跑：
   - `python3 news/tg_news.py channel` —— 公开新闻频道（默认 `LianDaShiNews`）上一个定时点以来的帖子，**主要新闻源**。
   - `python3 news/tg_news.py fetch` —— bot 所在群/频道里的新消息（你自己转发的等）。
   两边内容可能重复，合并去重。任一来源失败（比如 t.me 访问被拒）就在报告开头注明，继续用其余来源；全都没有就只用网络来源。
3. **主动上网搜财经新闻**（见下方「网络搜索」），和 Telegram 消息合在一起。
4. 按下方规范写一份汇总报告到本地临时文件，例如 `/tmp/tg_report.md`。
5. `python3 news/tg_news.py send /tmp/tg_report.md` 推送到个人 Telegram。
6. 发送成功后 `python3 news/tg_news.py ack`（没有 Telegram 消息时这一步也可照常执行，无副作用）。

任何一步失败：不要 ack（消息会在 Telegram 保留 24h，下次重拿），在输出里写清失败原因。

## 运行时间

每天 2 次（美东时间，周末照常，保证间隔 < 24h，Telegram 未确认消息只留 24h）：
- **07:45 盘前版**：覆盖前一天收盘后到现在的消息（隔夜、亚欧盘、财报、政策）
- **16:45 收盘版**：覆盖当天盘中的消息

## 网络搜索

用 WebSearch（必要时 WebFetch 打开原文），覆盖**上次运行以来**（约 9–15 小时）的新闻，每次大约 5–8 次搜索：

- **大盘行情**：盘前版查美股期货、亚欧股市、美元、10 年期美债、原油、黄金、比特币；收盘版查三大指数收盘、涨跌幅最大的板块和个股。
- **宏观与政策**：美联储官员讲话、经济数据（CPI、非农、PMI 等）、关税/贸易、地缘政治。
- **财报**：当天和次日的重要财报及盘后/盘前反应。
- **核实**：Telegram 里影响大但只有单一来源的消息，搜一下确认真假。
- **持仓**：`virtual_account.json` 非空时，查持仓个股的最新新闻。

优先 Reuters、Bloomberg、CNBC、WSJ、MarketWatch、Yahoo Finance、财联社、华尔街见闻等主流来源；只采用发布时间在覆盖窗口内的新闻，查不到就写查不到，不要编造价格或数字。

## 分析规范：一份汇总，不逐条分析

Telegram 消息（可能 50–100+ 条）和网络新闻**合在一起做一份综合研判**，不要每条/每个事件单独成段。

1. **筛选**：去重，合并同一事件的多条转发；广告、闲聊、与市场无关的直接丢掉（只在末尾记个数）。
2. **按主题归类**：如 宏观/美联储、政策/地缘、科技/AI、半导体、能源、加密、个股财报 等，按实际内容来分。
3. **只挑重点**：选出对市场影响最大的 **3–5 个主题**展开；其余低影响消息合并成一行"其他"带过。
4. 每个重点主题给出：
   - 一句话概括（合并该主题下所有相关消息），标来源：〔TG〕〔网〕或〔TG+网〕；可信度存疑的标注出来
   - **短期**（1–5 个交易日）/ **中期**（1–3 个月）/ **长期**（6 个月以上）方向，各一句话理由
   - 相关标的：指数、行业 ETF、个股 ticker，用 ↑ ↓ → 标方向
5. **整体结论**：本批消息对大盘短/中/长期的总体倾向（偏多/偏空/中性）。
6. **观察清单**：接下来最值得盯的 2–4 个数据、事件或日期。
7. 对现有持仓（仓库根目录 `virtual_account.json`，若有且非空）有直接影响时才提示，没有就省略。
8. 网络搜到、但 Telegram 没提到的重大事件也要纳入重点主题；不确定就写不确定，不要编造数字。

**篇幅**：整份报告控制在约 **1200 字以内**，2–3 分钟能读完，尽量一条 Telegram 消息发完。
